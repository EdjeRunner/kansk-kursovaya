# kansk-kursovaya

Skill для Grok: генерация полного курсового проекта (пояснительной записки) по методическим указаниям Канского технологического колледжа.

## Использование

Скилл срабатывает на запросы вида:
- сделай курсовую
- сгенерируй курсовой проект
- напиши КП по стандарту Канска
- курсовая по методичке
- РПЗ курсового

Скилл запрашивает данные студента/руководителя, объём и шаг генерации, затем выдаёт работу строго по частям в виде готовых .docx файлов.
